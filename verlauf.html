Verlauf

Tagesverlauf aus einer CSV-Datei in deinem eigenen Repository.

Noch keine Verbindung eingerichtet.

Die Daten liegen als CSV in einem privaten Repository auf GitHub. Der Token sollte nur für dieses eine Repository gelten, mit „Contents: Read and write“. Alles hier Eingetragene bleibt im Speicher dieses Browsers.

Diese Seite spricht ausschließlich mit api.github.com. Jede Änderung wird dort ein Commit und lässt sich über die Historie des Repositorys zurückholen. Ohne Netz zeigt sie den zuletzt geladenen Stand, ändern lässt sich dann nichts.

Ohne Verbindung ansehen: – oder die Datei auf dieses Fenster ziehen. Dabei wird nichts gespeichert.
